### Bug描述
管理员用户登录系统后，点击左侧导航栏的"用户管理"链接，页面自动跳转回登录页面，导致无法访问用户管理功能。

**具体表现**：
1. 使用管理员账号（admin/Admin123!）成功登录系统
2. 仪表盘页面正常显示，左侧导航栏可见
3. 点击"👥 用户管理"链接后，页面立即重定向到 `/login`
4. 浏览器控制台显示HTTP 401错误：`Failed to load resource: the server responded with a status of 401 (Unauthorized)`
5. 前端显示错误信息："获取用户列表失败: AxiosError: Request failed with status code 401"

### 根本原因分析
通过Playwright自动化测试和网络请求分析，发现问题的根本原因是：

1. **FastAPI尾部斜杠重定向机制**：
   - 前端调用 `GET /api/users`（无尾部斜杠）
   - 后端FastAPI路由定义为 `@router.get("/", ...)`，实际期望路径为 `/api/users/`
   - FastAPI自动返回 `307 Temporary Redirect` 重定向到 `/api/users/`

2. **HTTP重定向导致认证头丢失**：
   - 浏览器在跟随307重定向时，可能不会自动保留 `Authorization: Bearer <token>` 请求头
   - 后端收到无认证头的请求，返回 `401 Unauthorized`

3. **前端自动登出机制**：
   - 前端axios响应拦截器检测到401状态码
   - 自动清除localStorage中的token和用户信息
   - 触发路由守卫重定向到登录页面

4. **API设计不一致**：
   - 前端API服务层调用格式不统一，部分端点有尾部斜杠，部分没有
   - 后端FastAPI默认启用 `redirect_slashes=True` 导致自动重定向

### 修复方案
**文件**: `frontend/src/services/api.js` (第87行)

**修改内容**：
```javascript
// 修复前：
getUsers: (params) => api.get('/users', { params }),

// 修复后：
getUsers: (params) => api.get('/users/', { params }),
```

**修复原理**：
- 统一前端API调用格式，为所有集合端点（collection endpoints）添加尾部斜杠
- 避免触发FastAPI的自动重定向机制
- 确保认证头在请求过程中完整传递
