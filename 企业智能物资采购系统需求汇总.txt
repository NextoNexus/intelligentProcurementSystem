智能采购管理系统需求汇总文档
============================================

一、项目概述
------------
本系统是一个智能物资采购管理系统，旨在帮助企业实现采购流程的数字化、规范化管理。系统通过整合供应商管理、采购流程、库存控制和财务核算等功能，提升采购效率，降低采购成本，增强供应链透明度。另外系统还集成了简易AI智能助聊天框，方便用户和AI大模型进行简单交流。

二、系统特点和要求
------------------
1. 系统类型：OA系统（办公自动化系统）
2. 功能复杂度：功能不复杂，注重实用性和易用性
3. 兼容性要求：浏览器兼容性好，支持主流浏览器
4. 可扩展性：系统架构设计需具备高可扩展性，便于后续功能扩展
5. 易用性要求：界面简洁，操作流程清晰，无需花哨的界面动画，保证实用性和轻量性。
6. 总体前端界面架构为：左中右架构。左侧为菜单栏，中间面积最大的部分为主视图，右侧为简易AI智能体聊天框界面。暂时只需要支持文本聊天，不需要支持文件上传以及多媒体分析。

三、用户角色定义
----------------
1. 后台管理员：系统配置、用户管理、权限分配、数据维护
2. 部门领导：采购申请审批、部门采购需求管理、预算控制
3. 管理层：采购数据分析、决策支持、系统监控
4. 员工：采购申请提交、采购进度查询、个人采购记录查看

四、功能需求
------------

4.1 供应商管理模块
------------------
1. 供应商注册与准入
   - 供应商在线注册功能
   - 供应商准入流程管理
   - 供应商资质审核与评估

2. 供应商信息管理
   - 供应商档案建立与维护
   - 供应商基本信息（名称、联系方式、地址等）
   - 供应商产品目录管理
   - 供应商历史合作记录

3. 供应商评估与选择
   - 供应商绩效评估体系
   - 供应商评级管理
   - 供应商选择决策支持

4. 供应商协同
   - 供应商送货信息管理
   - 产品价格表维护与更新
   - 供应商沟通记录

4.2 采购管理模块
----------------
1. 采购需求管理
   - 部门采购需求提交
   - 采购需求池汇总与管理
   - 需求优先级设置

2. 采购申请流程
   - 在线采购申请提交
   - 采购申请审批流程
   - 申请状态跟踪

3. 采购执行管理
   - 采购询报价管理
   - 供应商报价比较
   - 采购订单生成与管理
   - 订单状态跟踪（待发货、已发货、已收货等）

4. 采购入库管理
   - 供应商送货单管理
   - 货物验收与入库登记
   - 入库单生成与确认

5. 采购退货管理
   - 退货申请流程
   - 退货原因记录
   - 退货处理跟踪

4.3 库存管理模块
----------------
1. 库存基础管理
   - 期初库存导入
   - 库存分类管理
   - 库存位置管理

2. 库存操作管理
   - 库存调拨管理（仓库间调拨）
   - 库存盘点功能
   - 库存预警设置（最低库存、最高库存）

3. 库存状态监控
   - 实时库存查询
   - 库存变动记录
   - 库存周转率分析

4.4 财务管理模块
----------------
1. 采购成本管理
   - 采购成本核算
   - 费用报销管理
   - 预算控制与预警

2. 发票管理
   - 进项发票录入与核对
   - 发票状态跟踪
   - 发票与采购订单匹配

3. 付款管理
   - 付款单生成与管理
   - 付款计划制定
   - 付款状态跟踪

4. 资金管理
   - 资金账户管理
   - 收款单管理
   - 资金流水记录

4.5 业务经营分析模块
--------------------
1. 采购数据分析
   - 采购需求统计分析
   - 采购金额与数量统计
   - 供应商采购占比分析

2. 库存分析
   - 库存期初期末统计分析
   - 库存周转率分析
   - 库存成本分析

3. 财务分析
   - 采购成本分析
   - 收支数据分析
   - 预算执行情况分析

4. 经营决策支持
   - 采购订单执行进度跟踪
   - 产品成本汇算
   - 供应商绩效分析报告

4.6 报表管理模块
----------------
1. 标准报表
   - 采购订单报表
   - 供应商采购报表
   - 库存报表
   - 财务报表

2. 自定义报表
   - 报表模板自定义
   - 数据筛选与导出
   - 报表定时生成

4.7 AI智能体聊天框模块
----------------
1. 智能聊天
      - 调用AI大模型API接口，和用户进行日常交流聊天。

2. 简易智能体助手
   - 基础功能：在当前用户的数据库访问权限范围内，支持数据表的查询，以及简单的数据分析，给出简单的总结，以供用户进行决策。注意：**仅支持数据库查询*，**不支持数据库的新增、修改、删除**
      -  具有可扩展性。开发者可以自定义模型上下文协议（MCP）服务器扩展。

3. 暂时只支持文本聊天，不支持文件上传，不支持图像视频音频生成。


五、非功能需求
--------------

5.1 性能要求
1. 系统响应时间：页面加载时间不超过3秒
2. 并发处理能力：支持至少100个并发用户
3. 数据处理能力：支持大数据量的采购记录存储和查询

5.2 可用性要求
1. 界面友好：操作流程直观，减少用户学习成本
2. 操作便捷：常用功能一键操作，减少操作步骤
3. 帮助文档：提供完整的在线帮助文档

5.3 可靠性要求
1. 系统稳定性：7×24小时稳定运行
2. 数据备份：定期自动备份，支持数据恢复
3. 故障恢复：系统故障后能在30分钟内恢复

5.4 安全性要求
1. 用户权限管理：基于角色的权限控制
2. 数据加密：敏感数据加密存储和传输
3. 操作审计：记录所有关键操作日志
4. 安全防护：防止SQL注入、XSS等常见攻击

5.5 兼容性要求
1. 浏览器兼容：支持Chrome、Firefox、Edge、Safari等主流浏览器
2. 移动端适配：支持移动设备访问

六、技术架构要求
----------------

6.1 代码运行环境
1. 后端运行环境为python，版本为3.11
2. 前端运行环境为nodejs，版本为22.16

6.2 技术栈
1. 数据库：PostgreSQL 18
2. 后端框架：FastAPI
3. 前端框架：Vue 3
4. 样式框架：Tailwind CSS 4
5. AI智能体开发框架：pydantic_ai
6. MCP服务器开发框架：mcp（可选）

6.3 系统架构
1. 前后端分离架构
2. RESTful API设计
3. 微服务架构（可选，根据系统复杂度决定）

6.4 部署要求
1. 支持windows10以上系统、Ubuntu22.04以上系统
2. 支持容器化部署（Docker）
3. 支持云平台部署
4. 支持本地服务器部署

九、系统适应性要求
------------------

9.1 业务流程适应性
1. 可配置业务流程：支持采购流程自定义
2. 灵活审批流程：支持多级、多条件审批
3. 扩展接口：提供API接口，支持与其他系统集成

9.2 功能扩展性
1. 模块化设计：功能模块独立，便于扩展
2. 插件机制：支持功能插件扩展
3. 配置化管理：系统参数可配置

十、附录
----------

12.1 术语定义
1. 采购需求：部门或个人提出的物资采购要求
2. 采购订单：向供应商发出的正式采购文件
3. 库存盘点：定期对库存物资进行清点核对
4. 供应商评估：对供应商的综合能力进行评估
